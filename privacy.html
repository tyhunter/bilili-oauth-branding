Privacy Policy

Last updated: July 20, 2026

This Privacy Policy explains how Bilili LiveTools YouTube Upload API handles information when a user connects their Google Account and uses the application to upload local recording files to YouTube.

Application purpose

Bilili LiveTools YouTube Upload API is a self-hosted utility that allows users to upload completed local live stream recordings to their own YouTube channel after explicit OAuth authorization.

Google user data accessed

The application requests YouTube API permission so it can upload video files to the YouTube channel authorized by the user. The application may receive OAuth access tokens, refresh tokens, YouTube channel information, video upload status, and uploaded video identifiers or URLs as part of this process.

How Google user data is used

  • To authorize uploads to the user's own YouTube channel.
  • To upload completed video recording files selected by the user or generated by the user's local recording workflow.
  • To check YouTube processing status and display upload results to the user.

Data storage

OAuth tokens and YouTube configuration are stored in the user's local deployment environment or local configuration files. The application does not operate a centralized service that collects these tokens from users.

Data sharing

The application sends video files and related metadata to YouTube only when the user has enabled upload and authorized access. Google user data is not sold, rented, or used for advertising.

Data deletion

Users can delete local configuration files from their own deployment environment to remove stored OAuth tokens. Users can also revoke this application's access from their Google Account permissions page. Uploaded videos can be managed or deleted from YouTube Studio by the channel owner.

Limited Use

The application's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
