# OAuth Branding Site

这个目录用于托管 Google OAuth 品牌验证所需的公开说明页面。

GitHub Pages 默认部署地址通常为：

- `https://tyhunter.github.io/bilili-oauth-branding/`
- `https://tyhunter.github.io/bilili-oauth-branding/privacy.html`
- `https://tyhunter.github.io/bilili-oauth-branding/terms.html`

如果绑定自定义域名，建议使用：

- `https://oauth.tyhunter.top/`
- `https://oauth.tyhunter.top/privacy.html`
- `https://oauth.tyhunter.top/terms.html`

Google Cloud OAuth 配置建议保持一致：

- App name: `Bilili LiveTools YouTube Upload API`
- Homepage URL: `https://oauth.tyhunter.top/`
- Privacy Policy URL: `https://oauth.tyhunter.top/privacy.html`
- Terms of Service URL: `https://oauth.tyhunter.top/terms.html`
- Authorized domain: `tyhunter.top`

重新提交验证前，请先用 Google Search Console 验证 `tyhunter.top` 域名所有权。
