YouTube upload integration

Bilili LiveTools YouTube Upload API

Bilili LiveTools YouTube Upload API is a self-hosted utility for users who record live streams locally and want to upload completed video recordings to their own YouTube channel.

This application is used with a locally deployed instance of biliLive-tools. After a user explicitly authorizes access with Google OAuth, the tool can upload finished recording files to that user's YouTube account and optionally remove the local video file after a successful upload to reduce local storage usage.

What the application does

  • Records live stream video files on the user's own computer or server.
  • Uploads completed local recording files to the user's own YouTube channel.
  • Displays upload status and the uploaded YouTube video URL to the user.
  • Optionally deletes the local recording file only after upload succeeds.

Why YouTube permission is requested

The application requests YouTube access only so it can upload videos selected or generated by the user's local recording workflow. The user controls whether YouTube upload is enabled and can revoke access from their Google Account at any time.

Requested scope: https://www.googleapis.com/auth/youtube.force-ssl

Data handling summary

  • The application does not sell Google user data.
  • The application does not use Google user data for advertising.
  • OAuth tokens are stored in the user's local deployment configuration.
  • Uploaded videos are sent to YouTube only after user authorization.
